# MRCP Tet Mesh v15 Refactor Notes

Date: 2026-05-19

This note records the small refactor performed after the OpenGATE 10.1 port. The goal was not to change the validated v14 behavior, but to start reshaping the prototype toward the OpenGATE `contrib.phantoms` style.

## 1. Motivation

The v14 example works, but it still looks like a research/prototype driver:

- the user script contains many implementation details;
- helper logic is large and specific to one example;
- the API is not yet similar to existing OpenGATE phantom helpers such as `add_iec_phantom(...)`.

For upstream discussion, a more natural target API is:

```python
from opengate.contrib.phantoms.mrcp import add_mrcp_phantom, add_mrcp_dose_actors

phantom = add_mrcp_phantom(
    sim,
    name="mrcp",
    phantom_type="adult_female",
    data_path="/path/to/MRCP_data",
)

add_mrcp_dose_actors(
    sim,
    phantom,
    organs=["heart", "lung"],
    spacing=2.5 * mm,
)
```

The current v15 work is a first step toward that shape.

## 2. Files Added

### 2.1 `opengate/contrib/phantoms/mrcp.py`

Path:

`/Users/yhuh/Study/installation/gate/Gate-10.1/opengate/opengate/contrib/phantoms/mrcp.py`

Purpose:

- adds a first contrib-style MRCP wrapper;
- exposes `add_mrcp_phantom(...)`;
- exposes `add_mrcp_dose_actors(...)`;
- defines `MRCPPhantomInfo` to keep geometry/scoring bookkeeping;
- defines `MRCPDoseSettings` to group dose actor options;
- keeps CopyNumberFilter-based scoring from v14;
- keeps full-geometry-by-default behavior.

Important implementation points:

- `add_mrcp_phantom(...)` creates the OpenGATE volume with `simulation.add_volume("G4Tet", name)`;
- `.node`, `.ele`, `.material`, and `.color` paths are passed to the `G4Tet` volume;
- region selection and copy-number map creation are still delegated to the validated v14 helper module;
- `add_mrcp_dose_actors(...)` attaches `CopyNumberFilter` objects directly with `actor.filter = ...`, which matches OpenGATE 10.1 behavior.

Current limitation:

- this file now uses package-local utilities from `opengate/contrib/phantoms/mrcp_utils.py`;
- the v15 example still reuses the v14 source/world/physics and visualization functions for behavior compatibility.

## 4. What Changed Compared With v14

v14:

- main script directly controlled most MRCP phantom setup;
- helper script contained most low-level parsing/filtering/scoring utilities;
- API was still example-specific.

v15:

- starts introducing a reusable public API in `opengate.contrib.phantoms.mrcp`;
- makes the user example shorter and closer to OpenGATE contrib phantom examples;
- preserves v14 source/world/physics and visualization behavior in the example for safety;
- removes the direct v14 helper dependency from the core `mrcp.py` wrapper.
